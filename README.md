# Dynamic Data Dashboard for Urban Planning and Development Insights

Welcome to the Dynamic Data Dashboard repository! This project is designed to provide an interactive and centralized platform for visualizing and analyzing urban planning and development data for Abu Dhabi (2020-2026).

## Features
1. **Business License Analysis**: Visualize trends in business licenses by sector and region.
2. **Population Demographics**: Explore population data segmented by age, gender, and region.
3. **Public Services Mapping**: Geospatial visualization of bus stops and public service centers.
4. **Multi-language Support**: Available in English and Arabic.
5. **Export Options**: Download reports and visualizations in various formats.

## Prerequisites
- Python 3.8 or later
- Required Libraries: `pandas`, `plotly`, `geopandas`

## Installation
1. Clone the repository:
   
   git clone https://github.com/your-repo/dynamic-dashboard.git
   cd dynamic-dashboard
   
2. Install dependencies:
   
   pip install -r requirements.txt
   

## Usage
1. Place the dataset files in the `data/` directory.
2. Run the Python script to generate visualizations:
   
   python dashboard.py
   
3. Access the interactive dashboard in your browser.

## Dataset Sources
- Business Licenses: `business_licenses.csv`
- Population Demographics: `population_demographics.csv`
- Public Services Data: `public_services.shp`
